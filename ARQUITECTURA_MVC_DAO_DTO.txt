🔑 CONCEPTOS CLAVE
================================================================================

1. DTOs (Data Transfer Objects)
   - Objetos simples sin lógica de negocio
   - Utilizados únicamente para transferir datos entre capas
   - Serializables para casos de sesión
   - Ubicación: src/DTO/

2. DAOs (Data Access Objects)
   - Encapsulan toda la lógica de acceso a datos
   - Implementan la interfaz IGenericDAO<T>
   - Manejan transacciones con commit/rollback
   - Utilizan JDBC para consultas SQL
   - Ubicación: src/DAO/

3. Controladores
   - Actúan como intermediarios entre Vistas y DAOs
   - Reciben DTOs del usuario
   - Llaman a DAOs para operaciones
   - Devuelven DTOs a las vistas
   - Ubicación: src/Controladores/

4. Conexión a Base de Datos
   - Clase Singleton: Conexion.getInstance()
   - Manejo automático de transacciones
   - Métodos: conectar(), commit(), rollback(), desconectar()
   - Ubicación: src/ConexionDB/

5. JSF + Bootstrap
   - Vistas en XHTML (sin scriptlets)
   - Componentes JSF: h:form, h:inputText, h:dataTable, etc.
   - Managed Beans con @ManagedBean
   - Estilos Bootstrap 5.3.0
   - Ubicación: web/

💻 USO DE LA ARQUITECTURA
================================================================================

FLUJO DE DATOS TÍPICO:

Usuario (Vista) 
    ↓
Managed Bean (JSF)
    ↓
Controlador
    ↓
DAO
    ↓
Conexión (JDBC)
    ↓
PostgreSQL

EJEMPLO: Obtener todos los clientes

1. Usuario accede a clientes.xhtml
2. ClienteBean.cargarClientes() es invocado
3. ControladorCliente.obtenerTodosLosClientes()
4. ClienteDAO.obtenerTodos()
5. Ejecuta: SELECT * FROM cliente
6. Retorna List<ClienteDTO>
7. Muestra en h:dataTable

🚀 INSTRUCCIONES PARA EJECUTAR
================================================================================

PRERREQUISITOS:
- Java JDK 8+
- Apache Tomcat 8.5+
- PostgreSQL 10+
- Maven o Ant (configurado en build.xml)

PASOS:

1. Compilar el proyecto:
   $ ant build

2. Desplegar en Tomcat:
   - Copiar WAR a CATALINA_HOME/webapps/
   - O usar Maven: mvn clean install

3. Acceder a la aplicación:
   http://localhost:8080/TRANSPORTESAQP

4. Login:
   Usuario: admin (o el que hayas creado)
   Contraseña: (la correspondiente en BD)
